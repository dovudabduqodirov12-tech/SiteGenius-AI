## ⚙️ O‘rnatish

### 1. Kerakli dasturlar

- [Node.js](https://nodejs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)

### 2. Loyihani ochish

ZIP faylni chiqarib ol va loyiha papkasini VS Code’da och.

### 3. Paketlarni o‘rnatish

Terminalni och va `package.json` joylashgan papkada bajar:

```bash
npm install
```

### 4. Serverni ishga tushirish

Agar `package.json` ichida `start` skripti mavjud bo‘lsa:

```bash
npm start
```

Terminalda ko‘rsatilgan `localhost` manzilini brauzerda och.

> ⚠️ Agar `start` skripti bo‘lmasa yoki backend sozlanmagan bo‘lsa, buyruq ishlamasligi mumkin.
